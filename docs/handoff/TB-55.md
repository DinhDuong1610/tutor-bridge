## Quyết định đã chọn
- Cookie phiên nằm trên domain web; Next gửi nó tới API trong header `Cookie`. Với lệnh ghi, Next tạo token CSRF ngẫu nhiên cho cả cookie `tb_csrf` và header `X-CSRF-Token`, kèm `Origin` = `TB_WEB_ORIGIN`. Next là bên gọi tin cậy; chặn CSRF giữa trình duyệt và Next là kiểm Origin của Server Action và SameSite=Strict.
- Kiểm phiên thật bằng `listOwnSessions` (`/me/sessions`, `limit=1`) vì hợp đồng không có thao tác "tài khoản hiện tại".
- Chạy thật cho thấy phần tĩnh của trang con vẫn có trong nội dung trả về khi layout chuyển hướng (prerender một phần). Dữ liệu không lộ vì API kiểm phiên; quy tắc mỗi trang tự gọi `verifyAdminSession()` ghi vào `conventions.md`.
- Chưa kiểm vai trò ADMIN ở web: `listOwnSessions` không trả vai trò. API kiểm quyền từng thao tác quản trị; MFA ở TB-13.
