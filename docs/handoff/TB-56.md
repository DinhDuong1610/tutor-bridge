## Quyết định đã chọn
- Server Action trả dữ liệu thuần (`ActionResult`) để đi qua ranh giới máy chủ và trình duyệt; 401 chuyển hướng ngay trong action.
- Khóa idempotency sinh ở trình duyệt theo từng thao tác, giống mobile; Server Action không tự sinh khóa, vì thử lại phải gửi lại đúng khóa cũ.
- Lời gọi action bị lỗi ở trình duyệt (mất kết nối tới Next) coi là chưa rõ kết quả.
- `Notice` ban đầu dùng mã màu thô; đổi sang biến CSS `success`, `warning`, `destructive-surface` cùng giá trị đã đo ở mobile.
- `input` lấy từ registry shadcn như `button`, sửa import `cn`.
